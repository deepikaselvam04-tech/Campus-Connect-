# CampusConnect

CampusConnect is a student-focused career opportunity platform that helps students discover, save and track internships and job opportunities.

## MVP Features

- Opportunity search
- Internship and job listings
- Save opportunities
- Apply to opportunities
- Application tracking
- Local browser storage
- Responsive design

## Technology Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Project Objective

The goal of CampusConnect is to provide students with a simple and centralized platform for discovering career opportunities and managing their applications.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Explore opportunities.
4. Use the Save and Apply buttons.
5. Check Saved Opportunities and Application Tracker.

## MVP Status

This project is a working frontend MVP prototype.
